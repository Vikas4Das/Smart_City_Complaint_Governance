A full-stack Smart City Governance platform that enables citizens to register complaints and allows authorities to manage, track, and resolve civic issues efficiently.

📌 Features

👤 Citizen
Register & Login

Raise Complaint

Upload Image

View Dashboard

Track Complaint Status

🛠 Admin
Manage Users

Assign Officers

View All Complaints

Monitor Problem Status

Dashboard Analytics

👮 Officer
View Assigned Complaints

Update Status (Under Process / Solved)

Track Complaint Progress

🗺️ Map Integration
Users can select complaint location using map
Stores latitude & longitude
Helps visualize problem areas

🛠 Tech Stack

🔹 Frontend
React
React js Material
HTML, CSS, JS

🔹 Backend
Spring Boot
Spring Security
JWT Authentication
REST APIs

🔹 Database
MySQL
